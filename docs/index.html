Mothershipen español

El sistema MoSh de Foundry, completo en español de España: interfaz, hojas, diálogos, mensajes de chat y los compendios de las ediciones 0e y 1e.

Última versión Repositorio

Qué traduce

InterfazMás de 640 cadenas del sistema: hojas de personaje, criatura y nave, ajustes y avisos.
Textos fijosDiálogos, botones y mensajes que el sistema escribe en inglés dentro del código.
CompendiosCondiciones, averías, tablas y macros de 0e y 1e, con Babele; no se tocan los datos originales.
GlosarioGuardián, Cordura, Miedo, Cuerpo, Estrés, Determinación… coherente en todo el sistema.

Instalar en Foundry

Necesitas el sistema MoSh – Unofficial Mothership y el módulo Babele. En Add-on Modules → Install Module → Manifest URL:

https://github.com/ManuRomera/mr-mothership-es/releases/latest/download/module.json

Activa el módulo en tu mundo Mothership y pon Foundry en Español (Configuración → Idioma).
